2. Coupon A: nine ring resonators on a thick two-layer panel
------------------------------------------------------------
Design: 5 plies of 2116, 0.637 mm thick, Dk 4.08.
A 50 ohm trace is 1.25 mm wide. eps_eff 3.074.

If the resin content drifts across the panel:
resin wt%   thickness mm     Dk   impedance ohm   ring mode 1 GHz
       45          0.558   4.20            45.5             1.678
       50          0.637   4.08            50.0             1.710
       55          0.734   3.97            55.0             1.741

How far a 1% rise in Dk moves each ring resonance:
  mode 1: 1.710 GHz, moves -7.5 MHz
  mode 2: 3.420 GHz, moves -15.0 MHz
  mode 3: 5.129 GHz, moves -22.5 MHz
With the maker's Dk of 4.49, mode 1 would be 1.638 GHz.
