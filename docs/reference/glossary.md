# Words used here

| Word | Meaning |
|---|---|
| **B-stage** | Resin that is part-cured: dry to handle, and still able to melt and flow in the press. |
| **Coupon** | A test pattern etched on a panel. |
| **Dielectric constant (Dk)** | How much a material slows and concentrates an electric field, against a vacuum at 1. |
| **`eps_eff`** | The effective dielectric constant a trace sees, when part of its field is in the board and part in the air. |
| **Fill** | The yarns that run across the roll of cloth. Also called weft. |
| **FR-4** | The flame retardant grade of glass and epoxy laminate. |
| **G-10** | Glass and epoxy laminate with no flame retardant. |
| **Laminate** | Plies pressed and cured into a rigid sheet. |
| **Matte side** | The rough side of copper foil. It is the side that bonds to the resin. |
| **Microstrip** | A trace on top of the board with a ground plane underneath. |
| **Ply** | One sheet of cloth with its resin. |
| **Prepreg** | Cloth already coated with B-stage resin. |
| **Resin content** | The resin's share of a ply's weight. |
| **Ring resonator** | A closed loop of trace. It resonates where a whole number of wavelengths fits round it. |
| **Skew** | The difference in arrival time between the two traces of a pair. |
| **Style** | The number that names a cloth, such as 2116. |
| **Treater** | The factory machine that draws cloth through varnish and then through an oven. |
| **Varnish** | Resin and hardener dissolved in a solvent, ready to coat cloth. |
| **Warp** | The yarns that run along the roll of cloth. |
